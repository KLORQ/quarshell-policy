# quarshell-policy

Policy parsing, validation and composition for Quarshell sandboxes.

The package exposes bounded policy parsing, typed evaluation inputs and policy composition used by runtime components.

## Install

```sh
go get github.com/KLORQ/quarshell-policy@latest
```

## Development

```sh
go test ./...
```

Requires Go 1.27 or newer. See the [Quarshell documentation](https://klorq.github.io/sandbox.dev/) for product guides and compatibility status.
